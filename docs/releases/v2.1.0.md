# My eBird Map 2.1.0

Prepared on 26 October 2026. This minor update adds features to the Mapbox app without changing the eBird CSV/ZIP input format.

## Changes

- Guided first-visit download and import flow, explicit demo selection, visible local-save status, and always-visible optional Drive backup controls in My data.
- Confirmation before replacing an imported dataset, inline import errors, and clearer loading and backup progress.
- Individual locations for new users; existing view choices, appearance, filters, result options, completed custom areas, and map position persist in the browser.
- A deterministic fictional demo with 286 species, 277 locations, 1,374 checklists, and 20,565 observations across 11 countries and ten years.
- Regional exotic-status rules applied during import, including county overrides, observation-level status precedence, and species-list status indicators with count tooltips.
- A map that fills the viewport, an 800px maximum stats-bar width, readable policy links in Settings, and project and support links in the sidebar.
- Optional Google Analytics event tracking after consent, with controls to change the choice in Settings.

## Validation and limitations

Lint, model/map checks, all 13 automated tests, the production build, and bundle checks pass. Browser checks cover desktop and mobile layouts, saved settings, demo loading, import cancellation and errors, successful import, and reopening saved observations. Generated demo records were checked for taxonomy matches, valid coordinates and dates, and varied counts.

Google Drive transfers still need real-account acceptance checks. Regional defaults cannot reproduce every checklist override; missing county information and taxonomy differences can affect species totals. Existing observations must be re-imported to apply the bundled exotic-status rules. French names and full support for very large spherical or polar polygons remain outstanding.

This commit prepares the version locally; publication and deployment are separate actions.
