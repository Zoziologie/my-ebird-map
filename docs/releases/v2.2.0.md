# My eBird Map 2.2.0

Prepared on 28 October 2026. This minor release adds geographic coverage, shareable view settings, updated reference data, and repeatable browser and performance checks while preserving the CSV/ZIP import format and existing browser storage.

## Changes

- Global region view covering all 3,669 eBird regions across 200 countries and territories, using 3,611 source polygons and 58 explicitly marked synthetic illustrations. Per-country assets load on demand. Source mappings, preparation scripts, licences, coverage reports, and boundary attribution are included.
- Updated country boundaries and official eBird country/region names, including territory handling and one representative High Seas aggregate in country and region views.
- Bundled official eBird API v2026 taxonomy with pinned provenance, version, and SHA-256. New imports and Drive backups record taxonomy metadata. Demo names match the updated taxonomy.
- URL-synchronized map position, grouping, selected taxa, date filters, display preferences, and completed custom areas. Shared links restore view settings when observations are available on the receiving device.
- Stable discrete map color categories by metric and grouping, selection-aware scales, updated region markers, and table-to-map location highlighting.
- Refined desktop/mobile presentation, settings, help, and analytics-consent controls.
- Faster map grouping, cached table aggregation, reused number formatting, fewer temporary arrays, and a demo factory that allows replaced demo observations and taxonomy indexes to be garbage-collected.
- Production-build browser checks for desktop/mobile Chromium and WebKit, accessibility and overflow checks, import/reload/filter regressions, Chromium retained-heap checks, optional live Mapbox checks, gzip bundle budgets, and a browser CI gate before deployment.

## Validation

Lint, formatting, 33 unit tests, app checks, production build, and bundle budgets pass. Private reference checks reconcile the full 188,407-row export, nine filter/polygon scenarios, country/region totals, and exact cluster unions at five zoom levels. The four desktop/mobile browser configurations pass the synthetic demo/import/reload/search/sort/filter, accessibility, layout, and heap checks. Live Mapbox integration checks passed on desktop and mobile Chromium; live WebKit cases were not run.

In a local three-repetition comparison, full-export median grouping times improved from 118.7 to 88.1 ms for locations, 110.2 to 56.9 ms for countries, and 145.8 to 89.1 ms for regions. These are local samples, not general performance guarantees. The export benchmark did not demonstrate lower process-wide peak memory. See [testing and benchmark details](../testing.md) for measurement scope and commands.

## Compatibility and limitations

Existing saved observations retain their earlier normalization until re-imported; re-import a current eBird export to apply v2026 taxonomy and current regional exotic rules. Regional defaults and unresolved counties cannot reproduce every checklist-level status decision or guarantee equality with an eBird life list.

Illustrative region partitions are explicitly labelled approximations. Browser device emulation does not establish physical-phone performance; automated accessibility checks do not replace manual assistive-technology review. Google Drive transfers still need real-account acceptance checks. French names and very large spherical/polar polygon support remain outstanding.
