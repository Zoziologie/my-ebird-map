# My eBird Map 2.0.0

The map-first rewrite replaces the legacy Vue/Leaflet app as the main application.

## Available in the app

- Mapbox globe and flat projections, with light/dark themes and several basemaps.
- Species, checklist, observation, and location map metrics, with purple–teal–yellow count-based colours.
- Automatic clustering with distinct species/checklist counts, country polygons with circle fallback, region circles, and an unclustered location view. Shared country boundaries load only on demand. A map-side Group by menu also starts polygon selection. Observation map labels use K/M notation.
- Search and lists for species, checklists, and locations; four year/month dropdowns for an inclusive From–To range in Settings, applied across the map and lists.
- Polygon selection with exact containment, draggable corners, double-click completion, Undo, and Delete. Counts update during editing, switching to updates on release when dragging refreshes are slow.
- Taxonomic roll-up to species while preserving spuhs, slashes, hybrids, and other original identifications. Species totals can still differ from eBird when an export lacks exotic status.
- CSV/ZIP import in a background worker, persistent browser storage, configurable Google Drive Save/Load, and responsive mobile layout.
- Location species/checklist totals link to the corresponding personal eBird pages.

## Known limitations

CSV/ZIP imports persist in browser storage. Google Drive Save/Load is implemented; real-account acceptance remains outstanding; see `docs/google-drive-setup.md`. French bird names and Google Analytics are not implemented. The UI is English. Very large spherical and polar polygon selections need further geographic handling.

The production build includes synthetic demonstration data and versioned public reference assets. Personal CSV exports, derived samples, private profiles, API secrets, and local configuration are excluded.

## Validation

ESLint, Prettier, model/map checks, six CSV/ZIP tests, and the production build and bundle checks pass. Private regression cases cover the full 188,407-row export, a representative sample, and a complete checklist, with independent Python reference counts. Browser import and IndexedDB reopening match those counts; the responsive layout was checked at 390 × 844. See [testing and benchmark details](../testing.md).

The GitHub Pages workflow deploys pushes to `main` after checks pass. See [deployment configuration](../deployment.md).
