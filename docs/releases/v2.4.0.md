# My eBird Map 2.4.0

Prepared on 29 October 2026. This release updates map controls and saves view choices locally, with fixes for country markers and cluster colors.

## Changes

- Restore map settings, filters, selected species, camera position, and custom areas from browser preferences when returning.
- Fix stale country circles and cluster colors rejected by Mapbox in production.
- Refresh map controls and dependencies, add a GitHub navigation link, and update the README with screenshots and a replay video.

## Compatibility

View settings are stored in the browser. URLs no longer customize the map view, so links relying on the previous URL parameters will not restore those settings. Imported data remains stored locally, with optional Google Drive backup and restore.
