# Releases

The current package is `3.4.0`. The Mapbox rewrite began with [3.0.0](v3.0.0.md), followed by [3.1.0](v3.1.0.md), [3.2.0](v3.2.0.md), [3.3.0](v3.3.0.md), and [3.4.0](v3.4.0.md). Version 3.4.0 also includes the 27 October 2026 exotic-status matrix update.

Earlier milestones are labeled retrospectively from the available commit history; they were not originally published as these releases. Version 1.0.0 marks the 2018 original app, 1.1.0 the 2019 hotspot improvements, and 1.2.0 the March 2021 Bootstrap and upload changes. The November 2021 analytics-only change is 1.2.1. Version 2.0.0 marks the February 2025 Vue/Leaflet app; the final pre-Mapbox snapshot is described in the [legacy notes](v2-legacy.md).

The 2026 rewrite was initially mislabeled 2.x. Its original commits and their embedded version strings are unchanged; the 3.x tags identify those historical snapshots under the corrected numbering. The old remote `v2.0.0` and `v2.2.0` tags were incorrectly assigned to the rewrite and have been replaced. Anyone who fetched them should delete and fetch those tags again. Pushes to `main` trigger the checked [Pages deployment](../deployment.md).
