# Releases

The main package is `2.3.0`. [Version 2.3.0 release notes](v2.3.0.md) cover checklist replay, shared continuous color scales, and polygon navigation improvements. [Version 2.2.0 release notes](v2.2.0.md) cover global region boundaries, shareable map views, the 2026 taxonomy, map presentation improvements, and automated browser/performance checks. [Version 2.1.0 release notes](v2.1.0.md) cover guided imports, persistent settings, a richer demo, regional exotic-status rules, and optional analytics. [Version 2.0.0 release notes](v2.0.0.md) describe the original Mapbox rewrite.

The legacy `1.1.0` source remains at commit `e8eb9587fe19462776266eecfae59eff9ac431d6`; [legacy release notes](v1.1.0.md) describe that snapshot. A legacy `v1.1.0` tag, if published, must target that explicit commit rather than the rewrite.

The `v2.0.0` tag identifies the tested rewrite commit. Pushes to `main` trigger the checked [Pages deployment](../deployment.md).
